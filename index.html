How recommendations work

The demo classifies each junction using its traffic percentage.

🟢 Below 45% — normal cycle

🟡 45–70% — balance traffic flow

🔴 Above 70% — consider rerouting

This is simulated data and rule-based logic. The system does not connect to cameras, sensors, live traffic feeds, or real traffic lights.
