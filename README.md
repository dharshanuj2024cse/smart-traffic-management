# FlowSense — Smart Traffic Management Dashboard
Frontend-only prototype using HTML, CSS, JavaScript, Leaflet, OpenStreetMap and Chart.js.

## Map changes
- Familiar map search box and Map/Satellite switch
- Standard street tiles and an optional satellite imagery layer
- Map zoom, center, fit-all-intersections and junction search controls
- Colored congestion markers and clickable junction details

## Run and deploy
Open `index.html` with an internet connection, or upload all files to the root of your GitHub repository and enable GitHub Pages under Settings → Pages → Deploy from a branch → `main` → `/(root)`.

## Limitations
The street map is OpenStreetMap, not Google Maps. The satellite imagery is provided by Esri. Traffic markers, congestion levels and recommendations are simulated and do not represent live traffic. The dashboard does not control real traffic lights.
